# MIS Master System – screens

Front end for the Otto / C&B MIS Master System, hosted on GitHub Pages.

- `index.html`, `app.css`, `app.js` – the screens (plain HTML, CSS, JavaScript)
- `cb-theme.css`, `img/` – C&B Theme stylesheet and logos

No keys, passwords or data are stored here. Everything goes through the Worker at
`https://mis-api.candb-otto.workers.dev` (repo `candb-otto-mis-api`).
